The purpose of this project was to show how bus bunching happens - that is when two buses from the same bus line are next to each other.

It was demonstrated on the Bus Network in Wroclaw, using lines 145 and 146 which share a similar route. Simulations were performed to see various parameters (e.g. passener arrival times, passenger boarding speed, random events) can impact bus bunching. Results are presented in the poster. An animation of the buses is also included.
